Introduction

실습 결과 많은 학생들이 수만 교수님께서 업로드해주신 파일을 실행하는데 어려움을 겪었습니다. 이는 각기 다른 운영체제를 사용하고, 환경변수 업데이트 등 많은 부분들이 달라서 그런 것으로 추정됩니다.

앞으로 팀을 같이 꾸려나갈 학생들끼리 다른 운영체제를 사용하는 경우, 작성한 코드가 서로 호환되지 않을 가능성이 높아보입니다. 각자가 g++, cmake, SDL2가 잘 설치되어있다는 가정하에, 작성된 cross platform 코드와 cmake를 활용하면 다른 운영체제에서 모두 동일한 코드로 쉽게 빌드 후 실행까지 할 수 있습니다. (동일한 코드로 Windows 11, MacOS Tahoe, Ubuntu 22.04에서 실행을 확인했습니다.) cmake는 수많은 분야에서 자주 사용하므로, 이번 기회에 간단한 사용법을 알아두시면 앞으로의 연구나 개발에도 도움이 될 것으로 생각합니다.

물론 저의 코드가 정답은 아니며, 수만 교수님의 ppt를 따라서 잘 실행되면 그대로 사용하시거나 다른 방법을 찾으셔도 좋습니다. 다만, 환경 설정 중에 문제가 생기는 경우, 그리고 팀원과 코드를 공유하며 개발하는 과정에서 발생하는 오류를 해결할 수록 도움이 될 수 있기를 바랍니다.

As a result of the practice sessions, many students experienced difficulties running the files uploaded by Prof. Suman. This is presumed to be because everyone uses different operating systems and there are many discrepancies, such as environment variable updates.

If students forming a team use different operating systems, it is highly likely that their code will not be mutually compatible. Assuming everyone has g++, cmake, and SDL2 properly installed, utilizing the provided cross-platform code and cmake allows you to easily build and run the same code across different operating systems. (Execution has been verified on Windows 11, MacOS Tahoe, and Ubuntu 22.04 with the exact same code). Since cmake is widely used in numerous fields, learning its basic usage now will be helpful for your future research or development.

Of course, my code is not the only answer; if you can successfully run the project following Prof. Suman's slides, you may stick to that or find other methods. However, I hope this guide helps you resolve issues during environment setup and fix errors that arise when sharing code with team members.

Install cmake and g++

Windows

For Windows, please follow Prof. Suman's instructions to setup msys and g++.

After installing msys, run the following commands to install cmake and the C++ toolchain:

pacman -Syu
pacman -S mingw-w64-ucrt-x86_64-SDL2
pacman -S mingw-w64-ucrt-x86_64-toolchain mingw-w64-ucrt-x86_64-cmake

Then run the following commands to check if the installation is successful. (Must run on msys, not cmd).

which cmake && which g++

The result should look like this:

/ucrt64/bin/g++
/ucrt64/bin/cmake

If you see an error message (e.g., which : The term 'which' is not recognized), make sure you are using msys.

Using msys in Visual Studio Code integrated terminal

Open Visual Studio Code and press Ctrl+Shift+P.

Then, search for Preferences: Open User Settings (JSON) and click it.

You will find settings.json is opened. Copy and paste the following code (overwrite or append).

{
    "C_Cpp.default.compilerPath": "C:/msys64/ucrt64/bin/g++.exe",
    "cmake.additionalCompilerSearchDirs": [
        "C:/msys64/mingw32/bin",
        "C:/msys64/mingw64/bin",
        "C:/msys64/clang32/bin",
        "C:/msys64/clang64/bin",
        "C:/msys64/clangarm64/bin",
        "C:/msys64/ucrt64/bin"
    ], 
    "terminal.integrated.profiles.windows": {
        "UCRT64 Bash": {
            "path": "C:\msys64\usr\bin\bash.exe",
            "args": [
                "--login",
                "-i"
            ],
            "env": {
                "MSYSTEM": "UCRT64",
                "CHERE_INVOKING": "1"
            }
        }
    },
    "terminal.integrated.defaultProfile.windows": "UCRT64 Bash"
}

After relaunching Visual Studio Code (or the integrated terminal), the terminal should look like this.

Run which g++ && which cmake to check if msys is successfully running.

MacOS

Install Xcode Command Line Tools to install g++ (Automatically installs clang++ acting as g++).

xcode-select --install

Install and update homebrew. Follow all instructions in the document carefully. If you miss some steps, your installation might not succeed.

Run the following code to check the successful installation of homebrew:

brew update

If the installation was successful, run the following command to install cmake and sdl2:

brew install cmake sdl2

Then, run the following code to check the installation:

which g++ && which cmake

The result should look like this:

/usr/bin/g++
/opt/homebrew/bin/cmake

Linux

Run the following command to install cmake, g++, and necessary dependencies.

sudo apt update 
sudo apt install g++ cmake libsdl2-dev xvfb

Then, run the following code to check the installation:

which g++ && which cmake

The results should look like this:

/usr/bin/g++
/usr/bin/cmake

main.cpp

To provide cross-platform support, I have added and modified some code. For your custom usage, please copy and paste the code between the /* CROSS-PLATFORM */ comments.

/* CROSS-PLATFORM */ 
#include <SDL.h>
#if defined(__APPLE__)
#define GL_SILENCE_DEPRECATION 
#endif
#include <SDL_opengl.h>       

#include "imgui.h"
#include "imgui_impl_sdl2.h"
#include "imgui_impl_opengl3.h"
#include <stdio.h>

int main(int argc, char* argv[]) {
    // Initialize SDL
    if (SDL_Init(SDL_INIT_VIDEO | SDL_INIT_TIMER | SDL_INIT_GAMECONTROLLER) != 0) {
        printf("Error: %s\n", SDL_GetError());
        return -1;
    }

    // ============================================================
    // Setup OpenGL Context and GLSL Version per OS
    // ============================================================
    const char* glsl_version;
#if defined(__APPLE__)
    // macOS: Requires OpenGL 3.2 Core Profile and GLSL 150
    glsl_version = "#version 150";
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_FLAGS, SDL_GL_CONTEXT_FORWARD_COMPATIBLE_FLAG); // Required on Mac
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_CORE);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 3);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 2);
#else
    // Windows/Linux: Standard OpenGL 3.0 is sufficient
    glsl_version = "#version 130";
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_FLAGS, 0);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_PROFILE_MASK, SDL_GL_CONTEXT_PROFILE_CORE);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MAJOR_VERSION, 3);
    SDL_GL_SetAttribute(SDL_GL_CONTEXT_MINOR_VERSION, 0);
#endif

    // Create window with graphics context (OpenGL flag is required)
    SDL_WindowFlags window_flags = (SDL_WindowFlags)(SDL_WINDOW_OPENGL | SDL_WINDOW_RESIZABLE | SDL_WINDOW_ALLOW_HIGHDPI);
    SDL_Window* window = SDL_CreateWindow("Dear ImGui SDL2+OpenGL3 Setup", SDL_WINDOWPOS_CENTERED, SDL_WINDOWPOS_CENTERED, 1280, 720, window_flags);
    
    // Create OpenGL Context
    SDL_GLContext gl_context = SDL_GL_CreateContext(window);
    SDL_GL_MakeCurrent(window, gl_context);
    SDL_GL_SetSwapInterval(1); // Enable VSync

    // Setup Dear ImGui context
    IMGUI_CHECKVERSION();
    ImGui::CreateContext();
    ImGuiIO& io = ImGui::GetIO(); (void)io;

    // Setup Platform/Renderer backends (passing the OS-specific glsl_version)
    ImGui_ImplSDL2_InitForOpenGL(window, gl_context);
    ImGui_ImplOpenGL3_Init(glsl_version);
    
 /* End of CROSS-PLATFORM */

    bool running = true;
    while (running)
    {
        // Handle events
        SDL_Event event;
        while (SDL_PollEvent(&event))
        {
            ImGui_ImplSDL2_ProcessEvent(&event);
            if (event.type == SDL_QUIT) running = false;
        }

        // Start ImGui frame
        ImGui_ImplOpenGL3_NewFrame();
        ImGui_ImplSDL2_NewFrame();
        ImGui::NewFrame();
        
        // Your UI goes here
        ImGui::Begin("Hello ImGui!");
        ImGui::Text("Welcome to Dear ImGui!");
        ImGui::End();
        
        // Render
        ImGui::Render();
        glViewport(0, 0, 1280, 720);
        glClearColor(0.1f, 0.1f, 0.1f, 1.0f);
        glClear(GL_COLOR_BUFFER_BIT);
        ImGui_ImplOpenGL3_RenderDrawData(ImGui::GetDrawData());
        SDL_GL_SwapWindow(window);
    }

    // Cleanup
    ImGui_ImplOpenGL3_Shutdown();
    ImGui_ImplSDL2_Shutdown();
    ImGui::DestroyContext();
    SDL_GL_DeleteContext(gl_context);
    SDL_DestroyWindow(window);
    SDL_Quit();

    return 0;
}

CMakeLists.txt

Paste the following content into your CMakeLists.txt.

  • Add your custom source files to the SOURCES list.
    • (주석 처리된 부분에 본인의 .cpp 파일을 추가하세요)
  • Set the name of the executable file to be built in the add_executable command.
  • This configuration uses a cross-platform approach without hardcoding local paths.
cmake_minimum_required(VERSION 3.15)
project(ImGui_Project LANGUAGES CXX)

# Set C++ standard
set(CMAKE_CXX_STANDARD 17)
set(CMAKE_CXX_STANDARD_REQUIRED ON)

# 1. Define Source Files
set(IMGUI_DIR ${CMAKE_CURRENT_SOURCE_DIR}/libs/imgui)

# ==============================================================================
# [How to add new source files]
# Whenever you create a new .cpp file for your classes (e.g., src/Game.cpp),
# you MUST explicitly append its path to the 'SOURCES' list below. 
# ==============================================================================
set(SOURCES 
    src/main.cpp
    
    # Add your new source files here. Example:
    # src/GameManager.cpp
    # src/Player.cpp
    
    # ImGui core and backend files
    ${IMGUI_DIR}/imgui.cpp
    ${IMGUI_DIR}/imgui_draw.cpp
    ${IMGUI_DIR}/imgui_tables.cpp
    ${IMGUI_DIR}/imgui_widgets.cpp
    ${IMGUI_DIR}/backends/imgui_impl_sdl2.cpp
    ${IMGUI_DIR}/backends/imgui_impl_opengl3.cpp
)

# 2. Create the executable target
# The first argument will be the executable file name. Here, imgui_app will be the file name
add_executable(imgui_app ${SOURCES})

# 3. Configure Include Directories (-I flag equivalent)
# This allows you to use `#include "imgui.h"` instead of `#include "../libs/imgui/imgui.h"`
target_include_directories(imgui_app PRIVATE 
    ${CMAKE_CURRENT_SOURCE_DIR}/src
    ${IMGUI_DIR}
    ${IMGUI_DIR}/backends
)

# 4. Find and Link External Dependencies
# Ensure SDL2 is installed via your package manager
find_package(SDL2 REQUIRED)
find_package(OpenGL REQUIRED)

# 5. Link Libraries (-l flag equivalent)
target_link_libraries(imgui_app PRIVATE 
    SDL2::SDL2main
    SDL2::SDL2
    OpenGL::GL
)

# Windows-specific: Hide the background console window for GUI applications
if(WIN32)
    set_target_properties(imgui_app PROPERTIES WIN32_EXECUTABLE TRUE)
endif()

Build & Run the app

Execute the following commands in the directory where CMakeLists.txt is located.

mkdir build && cd build 
cmake ..

If it configures successfully, run the following command to compile the project, check the results, and proceed.

cmake --build .

Rebuild the App

Notice: If there are modifications strictly to the source code (.cpp files), you do not need to delete the build directory.

Simply run the following command inside the build folder to incrementally compile the changes:

cmake --build .

Only clear the contents of the build folder and re-run cmake .. if you add new files to the project or significantly modify the CMake configuration.
